# NoteSpace

## Изменения содержимого пространств

- Все изменения содержимого (узлы, связи, размеры, описания) вносятся **только в активное пространство**: `data/spaces/<activeId>.json`, где `activeId` берётся из `data/index.json`.
- Шаблоны (`src/core/templates/`) **не трогать**, пока пользователь явно не попросит перенести изменения в шаблон.
- Перед правкой файла пространства сделать резервную копию: `data/backups/<id>/<ISO-время>--before-<что>.json`. Программа показывает эти копии в списке «Резервные копии».
- Менять только нужные узлы и связи, сохраняя правки пользователя и порядок узлов. Запущенная программа (порт 5173) подхватывает изменения файла сама.
- Изменения кода программы (раскладка, отрисовка, интерфейс) делаются как обычно.
