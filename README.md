# NoteSpace

3D-база знаний: вложенные группы и записи, связи между любыми узлами, глобальные и локальные уровни, подсветка по тегам.

Три варианта одной программы:

| Вариант | Где данные | Как запустить / собрать |
|---|---|---|
| Разработка | файлы в `data/` (правятся и вручную, программа подхватывает сама) | `npm run dev` → http://localhost:5173 |
| Программа для Windows | `%APPDATA%\com.notespace.app\` | `npm run app:build` → установщики в `src-tauri/target/release/bundle/` |
| Веб-версия | в браузере посетителя (IndexedDB) | `npm run build:web` → статический сайт в `dist/` |

Программа для Windows и веб-версия при первом запуске получают стартовый набор: активное пространство из `data/` и демо (`scripts/bundle-starter.mjs`, запускается перед сборкой сам).

## Запуск в режиме разработки

```bash
npm install
npm run dev
```

Открыть http://localhost:5173.

## Сборка программы для Windows

Нужны Rust (`rustup`, инструментарий `stable-msvc`) и Build Tools for Visual Studio (C++). Затем:

```bash
npm run app:build
```

Результат:
- `src-tauri/target/release/bundle/nsis/NoteSpace_<версия>_x64-setup.exe` — установщик (рекомендуется для раздачи);
- `src-tauri/target/release/bundle/msi/NoteSpace_<версия>_x64_en-US.msi` — пакет MSI.

`npm run app:dev` открывает программу в окне Tauri с горячей перезагрузкой.

## Веб-версия

```bash
npm run build:web
```

Папку `dist/` можно выложить на любой статический хостинг (GitHub Pages, Netlify и т. п.): все пути относительные. Правки посетителя сохраняются только в его браузере; для переноса — «Экспорт» / «Импорт» в настройках пространства.

## Структура

- `src/core/types.ts` — модель данных (`Space`, `SpaceNode`, `Link`, `Tag`).
- `src/core/layout.ts` — расчёт координат: вложенная раскладка по группам (d3-force-3d, плоскость XZ) + высота по уровням.
- `src/core/templates/` — шаблоны пространств: пустое, «Книга Урантии», демо-проект.
- `src/storage.ts` — хранение пространств через dev-сервер (`server/dataPlugin.ts`).

## Данные

- `data/spaces/<id>.json` — по файлу на пространство. Файлы можно править напрямую: открытая программа подхватит изменения сама.
- `data/index.json` — какое пространство открыто.
- `data/backups/<id>/` — резервные копии: создаются перед обновлением из шаблона, удалением, восстановлением и по кнопке «Сделать копию».
- Шаблоны (`src/core/templates/`) нужны только для создания новых пространств и для явного сброса («Обновить из шаблона»).
- Папку `data/` удобно держать под git: видна история изменений.
- `src/core/filter.ts` — фильтр по тегам (любой / все).
- `src/viewer/viewer.ts` — 3D-отрисовка на three.js (только просмотр; будет переиспользоваться при экспорте).
- `src/main.ts` — панели редактора: фильтр, создание узлов, свойства, связи.

## Уровни

- **Локальный** (по умолчанию): `Y = Y группы + смещение нуля группы + уровень × шаг уровня группы`.
- **Глобальный**: `Y = уровень × globalStep`, независимо от группы. Такая запись соединяется с группой пунктирной привязкой и не растягивает её оболочку.

Пунктирное кольцо внутри группы показывает её нулевой уровень, то есть её систему отсчёта (отключается в «Настройках вида»).

## Раскладка и вид

- Оболочка группы рассчитывается так, чтобы целиком вмещать содержимое, включая оболочки вложенных групп. Записи на другой высоте могут стоять над вложенной группой, а не только сбоку от неё.
- **Расположение по кругу** (свойство группы): закреплённые в центре узлы стоят на оси, остальные равномерно по окружности.
- **Размер как…**: узел берёт размер другого узла. Группа берёт его как минимальный размер своей оболочки.
- **Стили** (настройки пространства): именованный набор цвета, формы и размера. Если изменить стиль, меняются все узлы, которые его используют.
- Подписи уменьшаются с каждым уровнем вложенности.
